# Customer runtime

Runtime entry point: [main.py](main.py). Dependencies: [requirements.txt](requirements.txt).
The catalog and supporting snapshots are intentionally empty. The distribution
marker enforces customer authentication and subscription restrictions.

See [customer setup](../customer/README.md) for hosting, GitHub authorization,
subscription onboarding and publishing customer-authored workloads.

Deploy only the reviewed export, not this working directory with local environments,
test data or development instructions. There is no bundled hosting/workload IaC.
